# M16 战斗调整与试玩核对

2026-09-09。依据用户已同意的 v0.2 方向完成本轮实现；趣味、难度和实体手柄手感仍等待用户试玩评价。

## 已实现

- 朵朵三段主动连击，0.30 / 0.30 / 0.38 秒；第三击更重。伤害在挥击起手后结算，收招末尾 120ms 可以缓存一次下一击，不会自动打一串。
- 闪避可取消挥击和蓄力；恢复 0.72 秒。暂停、失焦、受击、救援和换猫会清掉未完成动作与缓存。
- 团团短扑最多 72 像素，碰到敌人身体或树桩会提前停下；命中施法／近战预备可打断并留出 1.8 秒机会。
- 圆圆短按轻拍，0.55 秒蓄满后松手重拍；命中被团团标记的目标可接力掀翻。普通重复控制有免疫间隔，不能无限压制。
- 换猫时，离场猫仅对附近、视线可达、已创造机会的敌人追加一次攻击，接力有 3 秒恢复；反复换猫不能刷伤害。
- 普通命中、蓄满、准确挡招、打断、接力有独立画面或音效提示。短命中停顿只保留受击敌人的表现，不冻结另一位玩家或游戏时间。
- 前方 14 度内有限瞄准辅助，不转身追背后目标、不穿树桩。战斗中可选择 12% / 20% / 28% 摇杆径向死区，默认 20%。

## 战斗结构

第一段：荆棘团与两只追逐近战的嫩芽怪。第二段：硬壳、织藤花和嫩芽怪。第三段：灯芯树怪、织藤花、枝球；双人额外有一只嫩芽怪，单人减去。

织藤花锁定施法开始时的地面位置，读圈即可离开，也可用扑击或引冲锋打断。地面爆发和树怪震地不能靠正面一直举盾抵消。树怪前方减伤、侧后方可直接打，受损至半血加入独立预警的震地；准确挡招留下比普通格挡更长的反击时间。冲锋撞中其他普通敌人也会造成伤害和打断。

双人允许两个分别针对不同玩家的威胁，单人最多一个高威胁动作；同一玩家不叠加两次大招预备。阶段间短暂喘息后自动推进，伙伴倒下时等待救援。开战及结束集合仍需确认，失败只重试当前段。

## 当前验证证据

- 33 组逻辑／场景回归，共 638 项通过；含 25 项新增战斗检查。旧的立即扣血、单敌人、波间二次确认断言按新规则修改，仍保留攻击方向、遮挡、控制免疫、输入释放和救援检查。
- 真实输入脚本完成双人三段战斗，末尾体力 2 / 2、零重试，约 33.46 秒自动化运行；本次走了碰撞制造破绽的路线。盾挡／树桩路线另有 26 项规则与 9 项真实场景检查。自动化用时不是人类游玩时长。
- 单人由真实伙伴 AI 支持，分别以朵朵和圆圆进行战斗通关；完整单人及双人调桥 → 战斗 → 灯廊 → 休息存档旅程均通过。
- 站着连续攻击的对照在 60 秒模拟中没有通关，出现伙伴倒地和两次重试。该对照说明需要补救和走位，不代表人类难度已达标。
- 本机 Apple M5、Godot OpenGL Compatibility，四敌人持续存在的受控场景，预热 2 秒、采样 6 秒：721 帧，帧间隔中位 10.968ms、P95 14.485ms、P99 14.879ms、最大 16.145ms；引擎过程监测 P95 15.158ms、物理监测 P95 2.495ms。这是短时本机测试，未测 Windows 实体手柄端到端延迟，也不证明所有浏览器稳定 60 FPS。
- Web release 成功导出，本地内置浏览器进入选关／新双人战斗，切猫、双方确认、三敌人开场和暂停可见正常；新增字体与预警圈可显示。
- 受控战斗、震地、16:9 和救援截图用于视觉核对。使用原有美术区分体型、配色与配件，未增加新图集。

## 用户试玩重点

从原网页“继续 / 选关”进入“双人战斗”，也可选“单人战斗”。先试移动连击与闪避取消，再试团团打断后换圆圆重拍；留意第三段半血后的红圈。

需要用户继续判断：按键是否跟手、两人是否都有事做、目标顺序是否产生区别、失误后是否能理解并补救。约两分钟是设计候选，不以机器人通关时间代替人类时长验收。
