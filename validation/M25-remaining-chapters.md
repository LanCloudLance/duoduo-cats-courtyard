# M25：第二至第五章与回家尾声

当前是五章主线的短篇试玩实现，序章、第一章和旧庭院样板保留。新增章节可从上一章连续进入，也可从首页选择单人或同屏双人。没有达到原完整故事的 2–4 小时目标，也没有完成最终美术、换装系统与所有人物演出。本轮保留已获用户“好些了”反馈的 M23 音乐，仅修正第五章阶段切曲条件。

## 新增可玩内容

| 章节 | 核心玩法与剧情 |
| --- | --- |
| 第二章：团团，去那边等我 | 朵朵调导向灯和外侧绞盘，团团沿低道卸桥扣；两段桥锁定后取得爪钩，试拉环并放下短桥。两位到钟楼低窗，看见仍不可操作的圆圆。 |
| 第三章：这次一起走 | 外墙检修槽取灯芯，安装、定向并明确呼唤圆圆踩室内踏板；重逢后解锁圆圆。白猫保持光、团团扣桥锁、朵朵调导光板，锁成永久桥后明确收光，再自行照出出口，三位实体越过门墙后读路线图。 |
| 第四章：灯光躲起来了 | 找回摊主灯罩换修补布；阿灯说明开门事故与自己的担心。试验线路、查卡枝、看收送箭头，穿插两场战斗。三位修补外壳后仍要检测倒流；备用灯匣保留，朵朵决定继续帮忙，集合休息。 |
| 第五章：把回家的路点亮 | 先用已学工具搭维修通路，再做三阶段机器维修：方向与时机举盾，团团锁摆臂；圆圆主动引光到缓冲槽，朵朵开盖；固定安全光、拉卡枝、转轮逐段推进。机器停下后验证向外送光，由阿灯恢复网络，告别并集合确认回家。 |
| 回家尾声 | 放好装备、擦猫爪、摸猫，再由玩家主动选择安心休息。故事完成后房间仍可走动和摸猫。 |

单人解谜必须自己切换角色、定位与操作；没有 AI 代解。双人猫位可切两猫，待机猫仅沿已经安全开放的地面跟随，保持照光或牵拉时留在原位，维修危险阶段不自动跟随。普通战斗沿用现有 AI 协助与双人战斗系统。章末必须实际集合，归途门要求三位在场且朵朵与猫位分别确认。

章末才保存通关记录，单人/双人及第二至第五章分别隔离；保留序章、第一章与庭院记录。中途刷新不保存当前机关进度，暂停菜单可重玩当前章。网页记录只在当前浏览器，没有桌面跨设备同步。

## 两种体验视角的模拟复审

专业游戏评论视角：后半段现在有工具学习、三人重逢、线索验证、维修收束与日常回家的因果链，终局是方向、保持与时机协作，避免把修机器写成重复打血条。主要风险是关卡背景复用，机关仍偏示意图，普通战斗场沿用样板；标题提示有时仍把操作拆得太具体。程序可通关不代表推理已足够有趣，后续应优先通过真人试玩观察哪一步能自主发现、哪里重复切换、两人是否各有参与，再逐章改善演出与反馈。

小学生视角模拟（没有真实儿童参与）：找回圆圆、修好桥再回家目标容易理解；两猫外观、站位和工具行为有区别，失误保留已修阶段，困难时可主动请求提示。风险是文字密度、方向照光和多人集合操作，孩子可能照着标题执行而没有自己的判断。需要真人验收“能否从物件变化解释失败原因”“是否知道伙伴在保持操作”“能否在不读最后一层提示时自己试出办法”，不能以自动驾驶成功代替这些答案。

本轮没有 Windows 实体手柄、真实儿童、双人真人节奏或主观听感验收。玩家后续确认针对本次短篇试玩内容，不扩大为正式游戏完成。
