# 朵朵与猫猫 · 把回家的路点亮

Godot 4.7.2 / GDScript。此目录是游戏的开发源；`work/duoduo-web/game-source` 是发布时的对应快照。主线范围为序章、五章冒险与回家尾声；另保留庭院、灯廊、风铃及战斗的独立挑战。

## 角色与操作

朵朵负责重物、修理与举盾；黑猫哥哥团团负责精密爪钩、扑击打断；白猫弟弟圆圆在第三章重逢后入队，负责定光和蓄力重拍。两只都是曼基康。解谜由玩家亲自操作，单人用角色切换完成；战斗中的伙伴提供有限 AI 支持。

| 动作 | 单人键盘 | 双人键盘 | 手柄 |
| --- | --- | --- | --- |
| 移动 | WASD | 朵朵 WASD / 猫方向键 | 左摇杆 |
| 互动 | E | 朵朵 E / 猫空格 | 面键下 |
| 切换 | Tab，解谜 Q 切回 | Tab 切猫 | 面键上 |
| 工具 | R | 朵朵 T / 猫 R | 右肩 |
| 攻击 | F | 朵朵 F / 猫 J | 面键左 |
| 闪避 | Q（战斗） | 朵朵 Q / 猫 K | 面键右 |
| 想一想 | G | G | 左肩 |
| 举盾 | 战斗/第五章按住 G | 同左 | 按住左肩 |
| 记事 | H，V 请求提示 | 同左 | 返回键，上面键请求提示 |
| 暂停/继续 | Esc / Enter | 同左 | 菜单键 |

第五章 G 是举盾，提示从记事本获取。记事本上下键/左摇杆翻页；提示由观察逐步深入，只在主动请求时显示。圆圆按住攻击再松开重拍。波间确认由玩家决定，双人需要两位分别准备。

## 旅程和恢复

“新旅程”从家里的序章开始，沿完成互动连续进入五章与回家。“继续旅程”按人数恢复该轮最新章节。新旅程分配独立记录，不会误读上一轮通关结果；回访章节和独立挑战不覆盖该轮主线位置。

主线按白名单保存已经发现的线索、永久修复与机关配置，原子写入；记录区分单/双人。暂停时刷新安全进度。读档后光、盾、拉绳等临时命令需要重新操作；战斗从当前场次入口重新开始。旧 v1 通关档仍兼容。Web 保存在该浏览器的网站数据，桌面版及其他浏览器不会自动同步；无痕窗口不保证保留。

## 开发与验证

开发测试必须使用 `DuoduoCatsCourtyard-qa-*` 的实际 userdir，不能只改 project.godot 而忽略 override.cfg。测试用的 MCP addon、QA override 和测试驱动不进入游戏导出。

M27 的验证、独立评审与发布证据位于工作区 `work/m27`；章节状态测试、普通 InputEvent 路径、不同进程恢复、原生画面与 Web 各自有证据边界。已知解法自动通关不能用来报告陌生玩家首通时间、儿童理解或真人操作手感。原故事时长预算尚待测量，不通过重复搬运、等待或相同波次延长内容。

画面、声音和音乐的生成源/许可沿用各素材目录及对应发布记录。字体使用随包 OFL。仅以最新发布回执中的 Git SHA 与 Site 版本确认在线内容，工作区文件不等于已经上线。
