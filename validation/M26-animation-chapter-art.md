# M26 角色步态与后四章素材

2026-10-06。用户指出角色像幻灯片在移动，第一章以后素材未完成。本版替换三位冒险角色的行走来源，增加正面/背面、转向、落脚与工具姿态；补齐第二至第五章独立背景、机关、NPC、木桥/落差与回家素材。保留五章现有玩法、剧情与 M23 音乐。

## 实现与边界

角色以实际位移累计步态，相同距离对应相同步态，不使用墙钟时间驱动原地换脚。初始放置/大幅传送不播放移动帧；暂停 dt=0 冻结；停步约 0.08 秒转站姿。共享地面投影、固定角色比例防止整个人物因源图边界跳动。冒险角色使用八姿势与独立背面；工具使用伸手、拉拽、观察动作。家居另有服装正确的图集。

第二章是林边调桥/钟楼入口，第三章是钟楼内部与可见灯芯搬运，第四章是黄昏树根集市，第五章是树心维护与回家。门、桥叶、灯罩、NPC、木臂分节与真实机关状态联动；第三章画面映射、桥面和落差资产与可走区域对齐。C2–C5 四份 state 文件中 draw_world 以前的玩法代码与 M25 基线逐字一致。

源 PNG 不修改，运行时使用图集区域和色键透明。保留旧互动/战斗来源依赖。Web 导入纹理压缩使 release PCK 为 15,606,880 bytes，engine.bin 为 10,054,758 bytes，各文件小于 25 MiB。原始素材与提示约束记录见 docs/art/M26-asset-prompts.md。

## 证据

- 完整回归：69 个套件、1751 项检查、0 失败；包含 C2–C5 单人和双人正常输入通关，以及 87 项冒险、90 项家居动画检查。结果在 m26/regression-summary.json 和 regression-run.log。
- Web release 构建成功；空项目独立挂载最终 PCK，读取 6 份原始动作 JSON、依赖 PNG、实例化三种冒险/家居角色，32 项检查通过。避免源工程掩盖漏包。证据为 web-build.log、animation-pack.log 和 animation-runtime-manifest.json。
- 原生 OpenGL 19 张冻结状态场景图：C2/3 十张、C4/5 九张；可核对桥锁、窗口遮挡、灯芯、地图、市场、修复、离场与回家。它们标为 fixture，不是自然剧情通关录像。对应测试在 godot-tests/m26_*_visual_test.gd；多帧 macOS 捕获用 final-market-core-fixtures.gd 强制窗口焦点。
- 原生 6 秒、60 FPS 连续步态夹具含慢速横走、背面上行、停步、转向与再次停止；文件为 m26-native-walk-final.mp4，逐帧图为 m26-native-motion-contact-sheet.png。它测试实际连续移动表现，不能冒充章节试玩。
- 本地 release 网页实际启动并通过菜单逐一进入 C2–C5，核对新背景/角色/机关、暂停菜单正常，浏览器错误/警告记录为空。网页烟测与原生正常输入通关分开记录。

初轮通用回归错误地无参数运行 PCK 探针，该探针要求明确的包路径；修正回归分类并单独执行后通过。没有把无参数失败删除后冒充一次全绿。macOS QA 使用独立 user:// 数据目录；未触碰生产存档。

## 未完成的表现

慢速下仍有离散切帧和部分姿势间距不匀；黑猫尾巴/腰包的侧向过渡较快。家居只有正面三分之四角度，没有独立背面，部分同侧伸腿重复。某些团聚位置角色/名字牌较近。完整换装、专业补间与真人操作体验尚未验收；这版不等于最终美术。

本机验证为 macOS 原生与 Codex 本地浏览器，未声明 Windows 实体手柄或真实小学生验收。技术通关不代表主观好玩或动画已达到专业完成度。

## 复跑

m26/regression.py 是原工作区脚本快照，BASE 使用 outputs/duoduo-game 和 work/runtime；独立 checkout 需按本地路径调整。validation/godot-tests 保存测试，临时复制到 game-source/tests 并导入后运行，正式导出排除 tests。PCK 探针必须从独立空项目运行，示例见 m26/animation-review.md。
