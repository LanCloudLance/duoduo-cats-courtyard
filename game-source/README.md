# 朵朵与猫猫 · 把回家的路点亮

Godot 4.7.2 / GDScript。此目录是游戏的开发源；`work/duoduo-web/game-source` 是发布时的对应快照。主线范围为序章、五章冒险与回家尾声；开发模式另保留旧庭院、灯廊、风铃及战斗测试场。

## 角色与操作

朵朵负责重物、修理与举盾；黑猫哥哥团团负责精密爪钩、扑击打断；白猫弟弟圆圆在第三章重逢后入队，负责定光和蓄力重拍。两只都是曼基康。M28 全篇返工候选已实现：解谜由玩家亲自安排伙伴；普通战斗单人一位出战、手动换角，双人两名真人出战、第三位候补。探索中的三人修复不受战斗出战限制。

## 旅程和恢复

“新旅程”从家里的序章开始，沿完成互动连续进入五章与回家。“继续旅程”按人数恢复该轮最新章节。新旅程分配独立记录，不会误读上一轮通关结果；回访章节不覆盖该轮主线位置。

主线按白名单保存已经发现的线索、永久修复与机关配置，原子写入；记录区分单/双人和该轮旅程。实际发现的纪念物可在记事与归家回看，不因读旧档自动赠送。读档后光、盾、拉绳等临时命令需要重新操作；战斗保留已清完的段落，未清完的一段从安全处重新开始。旧通关事实可迁移，旧途中配置不伪造为新机制已解。Web 保存在该浏览器的网站数据，桌面版及其他浏览器不会自动同步；无痕窗口不保证保留。

设置分别控制音乐、音效、镜头震动与手柄震动。默认菜单提供完整旅程、继续、设置与已走过章节的回访；`--development-menu` 才显示旧独立开发入口。

## 开发与验证

开发测试必须使用 `DuoduoCatsCourtyard-qa-*` 的实际 userdir，不能只改 project.godot 而忽略 override.cfg。测试用的 MCP addon、QA override 和测试驱动不进入游戏导出。

M27 是本轮被拒绝的体验基线，其技术验证位于 `work/m27`。M28 的全篇重审、规格、实施进度与重新验证位于 `work/m28`；章节状态、普通 InputEvent 路径、不同进程恢复、原生画面与 Web 各自有证据边界。已知解法自动通关不能用来报告陌生玩家首通时间、儿童理解或真人操作手感。原故事时长预算尚待测量，不通过重复搬运、等待或相同波次延长内容。正常菜单单/双人已连续完成全篇667项检查，六进程战斗恢复110项、可携灯91项与角色策略反例分别验证；具体证据和限界见 validation/m28。完成状态以最后发布回执为准，本文不构成儿童趣味或硬件体验通过。

画面、声音和音乐的生成源/许可沿用各素材目录及对应发布记录。字体使用随包 OFL。仅以最新发布回执中的 Git SHA 与 Site 版本确认在线内容，工作区文件不等于已经上线。
