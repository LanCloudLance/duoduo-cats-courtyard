# M27：五章完整候选与持续研发闭环

这一轮把现有序章、五章与回家尾声统一为同一旅程。入口、解谜规则、三位角色的战斗分工、途中恢复和场景反馈一起改动；完成后经过普通输入串关、独立反例评审、实际原生画面和网页操作检查。它是现有五章范围的完整可玩候选，游戏是否有趣仍由真实玩家判断。

## 玩家能看到的变化

| 模块 | 当前行为 |
| --- | --- |
| 新旅程与继续 | 从家中序章开始，六段文件属于同一个 run；单人、双人分别继续。回访章节和旧挑战不改当前旅程指针。写入失败时有持续可见提示，成功回读才清除。 |
| 序章与第一章 | 真的撑门、抓住并拖动地毯；沿用已建立的枝架、挡风罩和通风规则。工具与提示分开，保持中的动作可见，人物换位保留方向输入。 |
| 第二章 | 两桥共用唯一撑扣。前桥永久锁定后复用；后桥要由朵朵接住重量，团团才能带扣去远端锁定。失焦或撤承重时安全回落，并保留已抬到位的棘轮，不要求重新搬一整段。 |
| 第三章 | 入光高度改变同一镜面的入射方向，两块接收铜片只接受正面光。可先解高锁或低锁；错误光路、镜面背面与暂时断光有实际后果。扩大侧厅并将操作点移出光路，修正中心误触。 |
| 第四章 | 主线、连通旁路、隔离旁路的三次观测留在三块结果牌上。试验未完成不记录结论；补罩后还会显示“外罩已修好、主线仍回流”的区别。阿灯、归途匣与决定留下的因果对应实际证据。 |
| 第五章与回家 | 持盾卸载、两枚手动路销、三段不同方向的卸载与爪钩，最后由另一端实际确认灯光。机器暂态与永久修复分开；回家后有收装备、擦爪与自愿的家庭收尾。 |
| 战斗 | 朵朵连击、挡前方与闪避；团团短扑打断、留下接力标记；圆圆蓄力重拍与范围控制。普通剑不消耗猫爪标记。树桩两侧的通路、敌人站位和施法预告形成侧路选择。备用猫逐步找侧后位置，穿过预告时暂时变淡。 |
| 恢复与阅读 | 途中原子保存永久事实与有限对话记录；读档清除持续按住的光、盾、爪钩和临时电荷。H 打开记事并暂停，可滚动回看与按需提示。 |

## 验证与独立评审

连续主线脚本用正常 Godot InputEvent，从同一大厅实例依次完成序章、五章和回家；单人及双人都经过 first、shell、reserve 三场主线遭遇。最新 writer **641/0**，独立新进程 reader **52/0**。脚本知道解法、加速模拟；这不是首次游玩的时长、OS 键鼠或实体手柄验收。

独立评审先后复现并关闭 8 项主要问题，包括错误阶段回退、持盾换人后未释放、读档暂态、阶段存档与入口不一致，以及第三章邻近目标抢占。第二轮还独立通过高锁先解后恢复、承重失焦回落、三牌不同观察次序、真实猫爪命中与重拍接力、不同频率护盾到期，以及缺失／损坏旅程入口。报告分别见 `m27/review-integrated.md`、`m27/review2-integrated.md`。

原生画面检查区分连续移动与静态布局：独占的连续运动样本 61 秒，3661 帧，帧时间中位数 16.680ms、P95 17.859ms；另外 N4 战斗 1320 帧实际输入样本包含接力帧。静态光路／承重截图只证明特定场景布局。见 `m27/labels-results.md`、`m27/n4-results.md`。

网页在本机独立端口用 CUA 实际操作，不向引擎写入位置、阶段或解锁状态：移动、换角、记事、自然离场、撑门、抓毯、实际拖出41.083像素、暂停、刷新、继续相同 run与进度、重新完成地毯、自然进入第一章、再刷新通过直接继续进入第一章。JSON 状态只读观测仅在 debug 开启；正式 release 没有该观测入口。

最终回归 **100 套、3558 项检查，0 失败**；独立发布 PCK **36/0**，独立进程部分存档 writer/reader **7/0 + 6/0**。24 个快速 headless 套件仍报告 ObjectDB 退出警告，不宣称零泄漏。正式网页战斗在本机1280×900采样300帧：中位16.7ms，P95 17.5ms，未出现超过33ms帧；这是5秒呈现帧样本，不代表全部章节或Windows性能。

完整套件、独立 PCK、网页最终帧样本和构建哈希收录于 `m27/final-validation.json`。准确发布 SHA 与站点版本在发布完成后写入工作区发布回执，避免把待发布状态写成已部署。失败日志仍留在原工作区；测试选择错误、旧坐标、旧救援驾驶器与音频线程退出问题均有解释，不把失败藏成通过。

## 两种视角的当前判断

专业评论代理：第二章的同一撑扣、第三章的高度与正面入光、第四章的并列试验结果、第五章的持续卸载形成了可验证的因果。玩家有机会用观察改变方案；错误不会删除已取得的永久进展。战斗加入角色接力、敌人预告和侧路选择，但现有五章仍不是经过盲测验证的3–4小时商业内容。

小学生代理：最容易理解的是“谁托着桥”“光转错到哪”“三次试验有什么不同”。记事本能回看，提示按需递进；仍要留意第四章同时出现的主线、旁路、外罩等名词，以及忙乱战斗中的标记是否一眼可辨。以上来自成人代理和实测证据，不冒充真实儿童反馈。
