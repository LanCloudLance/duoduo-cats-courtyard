# M21 长循环：让三位角色有值得一起玩的事

用户授权：2026-10-02 要求自主长 loop，研究更多名作，改善音乐、关卡设计、空间拥挤、战斗及解谜，并以专业评论和小学生玩家视角评审后继续修正。采用当前会话原生执行；不反复请求范围确认。当前基线 6fd4b0d，网页版版本 11；完整剧情和三位角色保持。

## 成功标准和事实边界

- 不能用增加血量、敌人数量、闪光或测试数量代表趣味提升。
- 战斗至少提供普通追打以外的可行决策：抢先处理施法者、利用掩体／引冲锋、击飞场景种球制造开口。站位和角色能力影响结果。
- 场地实际变宽且变深；双人始终看见彼此，角色头部不被 HUD 遮住，最大同屏敌人保持四个。
- 当前仅有 0.1–0.65 秒音效，没有完整配乐。补原创主题、不同段落、场景编配和战斗强弱变化；音乐／音效独立控制，暂停和后台失焦安全。
- 解谜的主要问题是按物件顺序执行。新增风铃门作为灯廊的收束：镜面反射、分光镜位置、两路同时点亮的规则可以从场景观察；错解有真实光路结果，提示主动展开。单人自行切角色，AI 不解谜。
- 原有安全点、存档、网页、键盘、同屏手柄范围保留。无实体手柄的环境只能报告合成输入检查；小学生视角是 8–12 岁、已有游戏经验玩家的模拟评审，不冒充儿童实测。

## 取舍

方案 A 继续在小场地增加反馈／数值，投入小但无法改变玩家决策，放弃。

方案 B 整个项目换引擎与美术，代价大且无法先验证趣味，放弃。

选方案 C：原有试玩做三个可验证模块，改交互规则与空间，然后用实际运行证据复评。保留现有 Godot 及素材。

## 模块一：原创音乐与情绪节奏

离线生成六段原创器乐配乐：家中／菜单、庭院探索、灯廊／风铃、战斗、树怪压力、休息。共用短旋律身份，但改变和声、乐器、节奏和段落；每首至少 A/B 两段，包含休止，避免四音一直重复。不使用名作音频、旋律或第三方样本。

压缩 Ogg 文件；需要腾出网页包容量时，只调整背景图的导入压缩，保留原图和角色素材。音乐控制器放在大厅根节点；场景改变淡入淡出，暂停恢复原进度，主音量和音效不绑在同一开关。战斗过渡和休息不继续播放高压曲。

## 模块二：开阔林地与战斗选择

战斗 FIELD 改为 Rect2(-120,170,1520,650)，相较旧 1040×410 的实际移动面积约为 2.32 倍。固定同屏镜头居中 (640,480)，zoom 0.72；HUD 收窄，角色及预警有空间。使用原背景延展并绘制清楚边界，树桩视觉与碰撞位置保持一致。敌人不在角色身上生成。

加入两枚旋叶种球，位置 (650,460)、(1100,330)。普通攻击逐次松动，重击／第三段剑击可击飞；朝攻击方向滚动，撞树桩／敌人或时间结束后绽开，对敌人造成伤害与短暂开口，不伤伙伴。击飞后不能反复刷同一枚；重试当前段重置种球。

藤蔓施法留下有限时长的荆棘地带，先预警再生效；抢先打断可阻止生成。战斗依旧最多四敌人，避免扩大场地后只出现无压力追逐。测试定住攻击、只绕场和使用场景能力的差异，不能把万能安全角落当成完成。

## 模块三：风铃门，观察后改变关系

灯廊接桥之后进入共享画面的风铃门，再进入休息。独立直达入口便于反复比较。三个镜面 A(380,500)、B(680,400)、C(680,600)，分光镜可放在上托架 (380,400) 或下托架 (380,600)。源位 (180,500) 向右，接收铃为 (380,300) 与 (880,600)。光线按格点走，镜面 / 与反向镜面改变方向，分光镜同时送向前方与右方，循环光路有限终止。

第一段只要求点亮上铃，教一次反射；第二段展开后要求两铃同时持续亮 0.6 秒，玩家必须组合三镜和分光镜位置。朵朵近镜 E／面键下旋转 A/C；团团近镜 R／右肩拉动 B；圆圆在托架 R／右肩稳住分光镜，换猫不自动松手，移动自己才松开。错误角色、够不到、放错位置说明当前观察结果，不告诉完整答案。镜片角度、光路和铃声立即变化，达成后门永久打开，三位一起到出口确认。

不设置必须按某条步骤执行的隐藏检查；按实际光线是否到达接收器判断解法。用枚举配置和正常行动通关确认不存在虚假亮铃或不可恢复状态。体验复评若认为这段依旧机械，将继续调整其组合规则，而非靠更多文字包装。

## 长循环与停止标准

一轮：研究／诊断 → 实现 → 程序和画面检查 → 专业评论／小学生模拟评审 → 修正重大问题 → 复测。每项发现记录事实、推断、行动和结果。

必须完成至少一次整合评审后的修正回合；不能在最初实现或测试变绿时宣称闭环。专业评论检查节奏、策略、空间、谜题信息公平和声音；小学生模拟检查能否辨认自己、理解错因、尝试另一办法、失败后愿意再来。两种视角均可给否定结论，不用虚高评分。

发布门槛：新增机制有 RED→GREEN 证据，全部流程回归通过，网页构建及局部实机操作无阻断，托管容量合规，源码／构建一致，重大评审项已修正，未验证项有明确标注。最终发布原有访问范围并读回 GitHub 提交；用户仍拥有体验验收权。

## Independent review revision
扩大场地不得容许盲绕永久满血；施法按实际位移速度预判，但预警锁定后不能追着玩家移动，玩家转向、停步、闪避或打断均有意义。生产生成避开三位角色220像素。
风铃主谜题32配置：可调光源高度、双水晶分光、三面斜镜。右下公共镜子承接两路并同时改变两铃；单铃成功是可观察的中间结果。铃罩窗口只能接迎面光，背面经过的光继续前进。第一声铃拉开镜架，轨道动画期间暂不计算蓄铃或接收工具输入，避免位置突然变化误触。新安全点保存gate，旧版缺此字段显示未记录。
