# M15 完整庭院试玩

2026-09-08。已实现并完成本地验证；网页发布状态另以 Sites 发布结果为准。此记录不替代用户试玩验收。

## 本轮完成

- 四段连续试玩：合作调桥 → 三轮林间战斗 → 双猫灯廊 → 林边休息、保存、集合与结尾。
- 新灯廊使用独立地形、机关和社交动作图集。岸台、安全岛和路线由玩法坐标生成，不把概念图当作碰撞底图。
- 临时实面是当前路线与半径 56 光圈的交集；未照亮处只画虚线轮廓。固定桥按真实安全矩形绘制，熄灯仍可站。单人落脚点只在实际保留状态下显示。
- 朵朵操作镜台、团团接应、圆圆安稳定光；休息时坐下、蜷卧、摸猫和翻肚皮使用独立姿势，脚底位置仍由玩法决定。
- 休息区绘本环境、长椅、旅程记录牌和完成卡片。单关试玩显示实际进度，不冒充完整通关或覆盖上次旅程。结束后互动可回菜单。
- 原始素材留在 game-source/assets/visual-m15；图集通过 shader 在运行时移除洋红底色，未破坏生成原图。所有场景使用同一字体资源。

## 已验证的证据

1. 原有 31 组自动回归：605 项检查，0 失败。包含真实生产输入驱动的单人和双人四段连续通关、双猫灯廊两条路线、倒地救援、角色切换、键盘/合成手柄、暂停/断连、休息存档及重建场景恢复。
2. 新展示层检查：8 项，0 失败。覆盖操作姿势替换、渲染不能移动角色、暂停冻结、休息姿势、摸猫目标、完整/单关结尾区分、回菜单保持完成状态。
3. 原生实际 GPU 渲染：四条路分别亮灯/熄灯，共 8 个状态，通过抽样像素与 gameplay.allows 的比较，无实体路面越过真实支持范围。此测试不同于仅比较配置值。
4. 灯廊五张状态截图（含 16:9）和休息/结尾两张实际渲染截图检查。截图使用受控状态夹具，通关验证由上面的连续输入测试提供。
5. Web release 构建成功，无脚本或着色器错误。内置浏览器检查了首页、选关、灯廊、切猫、暂停和休息区；网页没有运行调试注入或存档夹具。连续完整通关证据来自本地自动化，不夸大为网页手工打通。

## 保留的界限

试玩流程完整，人物动作仍使用有限帧图集。用户此前提出的战斗不够流畅按要求保留当前 M14.1 实现，未宣称已经解决。连续方向动画、更多武器装备和完整换装不在本轮范围。

灯廊本轮以路线、机关、人物和反馈可读性为主；独立环境音效、进一步水面微动与更细的手臂绑定留作后续表现打磨。当前 Windows 实体双手柄、Switch、PS5 与 Safari 没有新增实机验收记录。

新原图、源码与验证记录随原私有仓库同步；不改变网站访问范围。存档文件路径和格式未变，本轮单关试玩不会覆盖先前安全点。
