# M11 试玩验收单

本轮目标：把现有庭院四段的非美术玩法收完整，再由你核对。代码、输入与流程检查已做；下面这些由你实际玩过后判断。美术继续使用临时素材。

## 先试完整单人

在准备页点击 **从头开始 · 单人**。一套键盘即可：WASD 移动，E 互动，Tab 换角色；解谜 R 用工具、Q 切回上一位，战斗 F 攻击、Q 闪避、G 举盾。手柄十字键选菜单，面键下确认，菜单键准备。

- [ ] 调桥：能看懂谁调绞盘、谁开卡扣，交替操作三轮后带三位过桥。
- [ ] 战斗：朵朵横扫与盾、团团短扑、圆圆蓄力重拍有明显区别；AI 有帮助，也留出自己的操作空间。
- [ ] 灯廊：知道怎样定光、移光、切回伙伴走路；Q 快速切回顺手，落脚保持能理解，没有变成无脑走直线。
- [ ] 路线：稳妥线和捷径体验有区别，失足后的恢复地点清楚。
- [ ] 结尾：三位到长椅坐下，恢复体力、保存；可摸猫，去出口结束。退出重开后“继续单人”回到长椅。

## 再试同屏双人

暂停后选择 **从头开始 · 双人**。P1 朵朵，P2 切换两只猫；两只手柄各自准备。也可暂用双人键盘：朵朵 WASD/E/F/Q/G，猫咪方向键/空格/J/K，Tab 切猫，R 工具。

- [ ] 两位都有持续参与感，尤其是战斗分工和灯廊同时照路、走路。
- [ ] 共享镜头与等待伙伴的距离合适，两只猫跟随不会挡住操作。
- [ ] 断开一只手柄会暂停；重接、认领和准备后能继续，不会突然移动或放出攻击。
- [ ] “继续双人”与“继续单人”保存互不覆盖；独立关卡试玩不会改掉已存记录。
